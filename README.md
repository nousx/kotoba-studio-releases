# Kotoba Studio

โต๊ะทำงานแปลการ์ตูนสำหรับ Windows 10/11 (64-bit)

**[ดาวน์โหลดตัวติดตั้งรุ่นล่าสุด](https://github.com/nousx/kotoba-studio-releases/releases/latest)**

เลือกไฟล์ `Kotoba.Studio_*_x64-setup.exe` หรือไฟล์ที่ลงท้าย `-setup.exe` แล้วติดตั้งในบัญชี Windows ที่ใช้ทำงาน

- OCR อังกฤษ ญี่ปุ่น เกาหลี จีน ใช้ในเครื่อง พร้อมปรับภาพเอียงด้วยมุม 4 จุด
- AI แปลผ่านบัญชี ChatGPT ตั้งค่าภายในโปรแกรมได้
- จัดตัวอักษร ฟอนต์ไทย 34 ตระกูล แต้มสีคลีน Undo/Redo
- เก็บตัวละคร สรรพนาม และความสัมพันธ์พร้อมโปรเจกต์
- บันทึกโปรเจกต์และส่งออกภาพภาษาไทย

## OCR ภาพเอียงและสถานะแปล (ตั้งแต่ v0.6.2)

เลือกกรอบข้อความ หรือสร้างกรอบด้วย T แล้วกด **OCR ภาพเอียง** เหนือภาพ ลากมุม **1 ซ้ายบน → 2 ขวาบน → 3 ขวาล่าง → 4 ซ้ายล่าง** รอบข้อความ ตรวจภาพที่ปรับตรงในแถบขวา แล้วกด **อ่านข้อความจากภาพปรับตรง**

รองรับข้อความหมุนเอียงและมุมมองแบบสี่เหลี่ยมคางหมู ภาพต้นฉบับและคำแปลเดิมยังอยู่ มุมบันทึกในโปรเจกต์และอ่านซ้ำได้ มี Undo/Redo, รีเซ็ตมุม และ Esc เพื่อปิดเครื่องมือ ส่วนกระดาษโค้งยังต้องตรวจและแก้ข้อความเอง

ระหว่าง AI แปลจะมีกล่องรอกลางจอพร้อมความคืบหน้า ป้องกันการกดซ้ำและแก้ไขงานขณะรอ กด **หยุดแปล** หรือ Esc ได้ คำแปลที่รับแล้วจะเก็บไว้

## เชื่อมต่อ ChatGPT (ตั้งแต่ v0.6.1)

1. กด **เชื่อมต่อ ChatGPT** ที่แถบด้านซ้าย
2. กด **ติดตั้งตัวช่วย** โปรแกรมจะดาวน์โหลดและติดตั้ง Codex CLI จาก OpenAI ให้
3. กด **เข้าสู่ระบบ ChatGPT** แล้วล็อกอินและอนุญาตบนหน้า OpenAI ในเบราว์เซอร์
4. กลับมาที่โปรแกรม แล้วกด **ทดสอบการแปล** จากนั้นเริ่ม OCR และ AI แปลได้

ไม่ต้องเปิด Terminal หรือกรอก API key หากเครื่องเชื่อมต่อ ChatGPT อยู่แล้ว จะข้ามการติดตั้งให้ มีปุ่มยกเลิก ตรวจสถานะ และเปิดหน้าเข้าสู่ระบบอีกครั้ง

ใช้โมเดล **GPT-6.1 Sol · Low** สิทธิ์และโควตาขึ้นกับบัญชี Codex ของแต่ละคน การทดสอบใช้โควตาจริงด้วยข้อความสั้น ๆ 1 ประโยค บัญชีใช้ร่วมกับ Codex บนเครื่องเดียวกัน วิธีล็อกอินอิง [OpenAI authentication](https://learn.chatgpt.com/docs/auth)

## อัปเดตโปรแกรม

ตั้งแต่ v0.6.0 โปรแกรมตรวจรุ่นใหม่อัตโนมัติตอนเปิด ปุ่ม **อัปเดต** อยู่มุมขวาล่าง กดเพื่อดูรุ่นใหม่และ **ดาวน์โหลดและติดตั้ง** โปรแกรมจะตรวจลายเซ็น บันทึกงาน แล้วติดตั้งและเปิดใหม่

รุ่น `.exe` เดิมต้องติดตั้งรุ่นใหม่ครั้งแรกหนึ่งรอบ จากนั้นกด **กู้คืนงานล่าสุด** เพื่อทำงานต่อ ปิด Kotoba หน้าต่างอื่นก่อนอัปเดต

## Extension โหลดภาพ

โหลด `Kotoba-Image-Collector.zip` จากหน้า Releases แตก ZIP แล้วเปิด Chrome/Edge → Extensions → Developer mode → Load unpacked เลือกโฟลเดอร์ที่มี `manifest.json` ใช้เก็บภาพที่เปิดอ่านได้ตามปกติ แล้วนำเข้า Kotoba Studio

## ไฟล์ใน Releases

- `*-setup.exe`: ตัวติดตั้ง Windows
- `*.sig`: ลายเซ็นสำหรับระบบอัปเดต
- `latest.json`: ข้อมูลรุ่นล่าสุดสำหรับโปรแกรม
- `Kotoba-Image-Collector.zip`: Extension

Repository นี้แจกตัวติดตั้งเท่านั้น ซอร์สของโปรแกรมเก็บเป็น Private ส่วนไฟล์ Source code ที่ GitHub สร้างให้มีเฉพาะเอกสารใน repository นี้

OCR และฟอนต์รวมอยู่ในโปรแกรม AI ใช้ Codex CLI ซึ่งกดติดตั้งในโปรแกรมได้ และต้องมีบัญชี ChatGPT ที่ใช้งานได้ ตัวติดตั้งยังไม่มีใบรับรองผู้เผยแพร่ Windows จึงอาจขึ้น Unknown publisher ในการติดตั้งครั้งแรก
